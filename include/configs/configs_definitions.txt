# Configuration Options Documentation

## CONFIG_CROP_VANILLA_MSG

If uncommented, the kernel may remove the vanilla dialogue text to save approximately 470 KB of ROM space in the DEMO.

> Note that enabling this config will make FEB think there is something wrong in the ROM and report a warning. However, it will be acceptable as this will not actually introduce any bugs.

If you are planning to develop a new game instead of making minor changes to vanilla, it is recommended to uncomment this config to save space.

## CONFIG_VERIFY_SKILLSYS_SRAM

If commented out, CHAX may not verify the FESKILL magic word in SRAM.

## CONFIG_USE_UTF8_GLYPH

If uncommented, use UTF-8 characters.

## CONFIG_USE_COMBO_ATTACK

Engage style combo attack.

## CONFIG_BATTLE_SURROUND

When a unit is attacked and adjacent to the enemy, each adjacent enemy may cause the unit's avoid to decrease by 10%.

If completely surrounded (an enemy on each side), the unit's defense may decrease by an additional 5.

Flyers in outdoor environments are not affected by this effect.

  -	0: Do not show any kernel tutorial
  -	1: Only show the kernel tutorial in tutorial mode
  -	2: Show the kernel tutorial at any time

## CONFIG_USE_CHAR_CUSTOM_ANIM

If uncommented, enable the patch:
FEB: Character Custom Animation

## CONFIG_FASTER_MAP_RANGE

If uncommented, the function `GenerateUnitCompleteAttackRange` will be faster but with lower accuracy.

## CONFIG_AUTO_NARROW_FONT

Try narrowing the font on skill-name/skill-desc/menu-disp.

## CONFIG_AUTO_DETECT_EFXRESIRE_WEAPON

Inject fake FEB old AnimNumber patch hooks.
This config may cause two functions to suffer from ugly ASM hooks:

  -	`StartBattleAnimHitEffect`
  -	`NewEfxHpBar`

Auto detect on EfxResire weapon judgment.

## CONFIG_BANIM_SWITCHER_EN

Enable patch: BanimSwitch

## CONFIG_USE_GAIDEN_MAGIC

If uncommented, enable the Gaiden style magic system.

## CONFIG_GAIDEN_MAGIC_MUST_BE_MAGIC

If set as 0, then all weapons will be acceptable (rather than magic weapons only).

## CONFIG_GAIDEN_MAGIC_REQUIRES_WRANK

If set as 0, then the unit can directly use the weapon regardless of the vanilla judgment.

## CONFIG_GAIDEN_MAGIC_AI_EN

If set as 1, the AI can also use Gaiden B.Mag.

## CONFIG_GAIDEN_EXT_CONF_EN

Enable `gGaidenChaxConfigs`.

## CONFIG_GAIDEN_MAGIC_REQUIRES_WRANK

	0:	All weapons are acceptable.

## CONFIG_STOP_COUNTER_ENABLED

	1.	Petrify should not stop battle.
	2.	Petrified/slept units should not attack.

## CONFIG_EFX_STATUS_DISPLAY_ON_EXTHIT

In battle animations (banim), unit status flashing is decided by ext-hit rather than `ANIM_ROUND_POISON`.

## CONFIG_C03_NOT_FLUSH_EFXSTATUS

C03 does not flush efx-status.

## CONFIG_UNLOCK_ALLY_MHP_LIMIT

Enable leadership features.

If uncommented, this will disable move-path calculation and display. Since the move-path can display no more than 20 steps in vanilla, with the increase of a unit's mobility, this limitation may cause a risk of overflow error. Thus, we directly remove the move-path to avoid overflow.

Install FEB patch: `SetHPClassLimit`
