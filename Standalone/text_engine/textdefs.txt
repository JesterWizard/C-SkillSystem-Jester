// Text engine control codes for clean FE8U.
//
// Aliases for the codes the text engine adds, in the "[Name] = byte, byte"
// format of Event Assembler's ParseFile and similar text tools. Each alias
// is the raw bytes to put in a message: 0x80 then the code, then any
// arguments. Arguments must not be 0x00, which ends the message.
//
// Codes 0x80 0x00 - 0x80 0x25 and 0x00 - 0x1D are vanilla FE8's own.
//
// The text engine also reads these names when a message spells them out as
// plain text, as FEBuilder's text editor saves them (make builds
// Source/TextAliasTable.h from this file).
