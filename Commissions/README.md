| Patch | Notes |
|-------|-------|
| [accessory_slot](accessory_slot/) | The last inventory slot is for one accessory (item ID list); other items fill the first four |
| [wary_fighter](wary_fighter/) | Follow-up block; per-unit always-on or enemy-init, plus a global toggle |
